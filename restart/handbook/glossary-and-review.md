# 术语与复述卡

英文首次出现配中文。下面的定义限定在本手册的使用场景，不把产品名当作算法名。

| 名词 | 中文与具体含义 |
| --- | --- |
| Embodiment | 本体／具身形态，包含机械结构、传感器和执行接口等条件 |
| DoF | 自由度，可独立描述运动的维度；不等于数据文件里任意向量的长度 |
| Observation | 观测，策略此刻可用的图像、状态等输入 |
| State | 状态；数据中的 state 常是部分机器人测量，不一定是完整世界状态 |
| Action | 动作，模型或操作者输出的控制目标，必须解释单位与控制模式 |
| Policy | 策略，根据观测生成动作的函数／模型 |
| Episode | 一段按任务开始和结束条件定义的轨迹 |
| Rollout | 策略与环境交互产生的一段或一批轨迹 |
| Batch | 批次，一次训练更新中组合的样本 |
| Chunk | 在动作策略里常指一段连续动作；存储中也可能指文件分片，需看上下文 |
| Mask | 掩码，用于标记有效数据、填充位置等 |
| Checkpoint | 检查点，权重和相关训练状态／配置的保存结果 |
| Normalization | 归一化，按约定的统计或范围改变数值尺度 |
| Calibration | 标定，确定传感器／几何／关节等参数或相互关系 |
| IK | 逆运动学，从末端目标求关节配置；不是神经网络策略的同义词 |
| Teleoperation | 遥操作，人通过某种输入设备实时控制机器人 |
| XR | 扩展现实，本手册用于头显跟踪与交互 |
| Host／PC2 | 宇树示例中的外置主机／机器人开发计算单元标识 |
| BC／IL | 行为克隆／模仿学习；BC 是从示范观测拟合动作的一类方法 |
| VLA | 视觉—语言—动作模型；具体输入输出因模型而异 |
| Actor／Critic | 动作网络／价值网络，强化学习中的常见职责 |
| Sim2Real | 仿真到真机迁移，包含动力学、观测、执行与时序差异 |
| World Model | 世界模型，学习动作条件下未来观测／状态等变化的模型 |
| SDK | 软件开发工具包，提供数据或设备接口等能力 |
| UI | 用户界面；跨平台 UI 不代表驱动与训练环境都可跨平台 |
| MIRAI | Micropsi 的商业视觉与学习控制系统产品名 |
| DEPRAG／UR16e | 装配工具厂商／优傲机械臂型号 |

## 每章都回答四句话

输入是什么？这一步做什么？输出交给谁？怎样知道做对了？

## 汇报前检查

- 能按时间讲出一个工序的设备、人员和控制交接。
- 能打开一份真实数据，指出图像、状态、动作、时间和轨迹索引。
- 能说明格式兼容、语义兼容和真实能力之间的区别。
- 能给出训练标签、损失、推理输入与预测结果。
- 能说明当前已验证到哪一步，以及需要设备或 GPU 才能补齐什么。
