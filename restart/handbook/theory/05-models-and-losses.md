# T5：五条策略路线、模型结构与训练目标

这里的“五条”是手册的工作分类，不是学界统一标准，也不预设等于此前口述的全部模型。世界模型单列在 T6。

记 `o_t` 为当前／历史观测，`l` 为可选任务语言，`A_t` 为未来 H 步动作。动作来自示范或其他明确来源。训练数据格式规定怎样存，训练目标决定怎样消费。

## 1. 行为克隆与 ACT

行为克隆（Behavior Cloning，BC）用监督学习拟合示范者在观测下的动作。简单回归可用 MSE：预测动作与标签的平方误差。

ACT（Action Chunking with Transformers，用 Transformer 预测动作块）将图像编码和机器人状态交给条件动作序列模型。训练时其变分编码器还读取示范动作来形成潜变量；预测器学习输出整段动作。推理时使用观测与指定的潜变量处理，不读取未来标签。[ACT 原始研究](https://arxiv.org/abs/2304.13705)

本手册固定 SDK 的 ACT 采用重建项与 KL 正则，概念式为：

$$L = L_{\mathrm{L1,masked}}(\hat A,A)+\beta D_{KL}(q_\phi(z\mid o,A)\Vert\mathcal N(0,I)).$$

掩码指轨迹边界填充的处理；具体有效元素如何归约以实现为准。KL 约束潜变量分布；它不是动作类别标签。视觉骨干、状态投影、Transformer、动作头和变分编码器均有参数。[固定 SDK 的 ACT 实现](https://github.com/huggingface/lerobot/blob/ca69a2068462a37f7cdcb74180927a2f863d2bf7/src/lerobot/policies/act/modeling_act.py)

## 2. 扩散动作策略

Diffusion Policy（扩散策略）在观测条件下学习动作分布。训练时对示范动作加噪，网络根据噪声等级和观测预测噪声等目标；常见噪声预测式为 `E[||epsilon-epsilon_theta(A_k,k,o)||²]`。标签除了示范动作，还包含采样出的训练噪声。

推理从噪声动作块迭代去噪得到动作，通常只执行部分，再读取新观测重新预测。它适合表达多种合理动作，代价之一是多步生成计算。[原始项目](https://diffusion-policy.cs.columbia.edu/)

## 3. 自回归动作 token VLA

VLA 是 Vision-Language-Action，视觉—语言—动作模型。OpenVLA 是代表：视觉编码器与语言模型骨干接收图像、任务语言，连续动作离散为 token 后训练预测。

目标可写作 `-sum log p(action_token_i | image, language, previous_tokens)`。推理生成 token 后解码、逆归一化为动作。它与 LLM 的交叉熵训练相似，区别在于输出 token 对应具体动作的编码规则。不是所有 VLA 都采用这种输出。[OpenVLA 项目](https://openvla.github.io/)

## 4. 流匹配 VLA

Flow Matching（流匹配）学习把噪声动作逐渐变为目标动作的向量场。简化地令 `x_tau=(1-tau)epsilon+tau A`，目标速度为 `A-epsilon`，用 `E[||v_theta(x_tau,tau,o,l)-(A-epsilon)||²]` 训练。不同实现的时间方向、噪声分布和参数化可能不同。

视觉语言骨干提供条件，动作专家生成连续动作块；推理通过若干积分步骤得到动作。π0 是相关代表。语言理解的迁移价值来自预训练，但新本体、动作编码和部署条件仍需适配。[π0 官方介绍](https://www.pi.website/blog/pi0)

## 5. 强化学习策略

RL（Reinforcement Learning，强化学习）通过与环境交互优化回报。数据主要包含观测、动作、奖励、结束标志等，不需要每步都有专家动作。PPO、SAC 等是算法，actor／critic 是常见网络角色；详见 T6。

## 数据与能力的对应

| 想改善的能力 | 需要增加或改善的数据 | 为什么可能有帮助 |
| --- | --- | --- |
| 对象识别与任务理解 | 多样图像、可靠任务描述 | 扩展视觉和语义覆盖 |
| 对准与操作 | 对应观测下有效且稳定的动作 | 提供控制目标与纠正样例 |
| 接触与质量 | 力、接触事件、过程曲线及质量结论 | 图像不足时补充交互与结果信息 |
| 失败恢复 | 偏离状态、接管与恢复过程 | 覆盖成功轨迹没有访问的状态 |
| 跨本体 | 本体描述、统一或可转换语义、多本体经验 | 支持学习共性并识别本体差异 |

这些是改善假设，要通过固定测试集或消融实验验证；新增数据不保证单调提升。相同格式不等于这些方法都消费相同窗口、相机、状态或语言。

## 本轮实操与边界

L3 真正运行的是缩小的官方 ACT：28 维教学数值、单相机、8 步动作块、5 次更新。视觉骨干随机初始化，不下载 VLA 权重。它验证计算链路，不能比较上述方法优劣或证明装配能力。

复述问题：ACT 的动作标签与扩散噪声目标有何区别？世界模型的未来画面是动作标签吗？把任务文字存在数据里是否就让 ACT 获得语言能力？
